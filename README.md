# Laboratório de Inovação III

Site da disciplina **Laboratório de Inovação III** (ADS, 3º semestre, noturno, Taguatinga), da Faculdade de Tecnologia e Inovação Senac DF. Profa. Maristela (Stela).

Publicado em **https://maristelaoliveira.github.io/lab-inovacao-3/**.

Os grupos planejam, desenvolvem e implantam um sistema com banco de dados (PHP e MySQL, da Web II), que vira o coração de um plano de negócio de base tecnológica.

- `index.html`: página da disciplina (ementa, aulas, avaliação, bibliografia)
- `aulas/aula-NN.html`: uma página por aula
- `assets/`: visual comum aos sites da professora (cópia do portal)

Feito com ♥ e sucata eletrônica.
