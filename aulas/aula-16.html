C1–C3 · conceitos

Fechando o projeto

C1

Planejado versus realizado

Comparem escopo, prazo e riscos com o que aconteceu de verdade. Projeto real sempre muda: o importante é saber explicar por quê.

C2

README que deixa qualquer pessoa rodar o sistema

Como instalar, como criar o banco a partir do banco.sql, como abrir o sistema e quem fez o quê.

C3

O pitch

Problema, solução, demonstração do sistema com dados de verdade, números do plano de negócio e próximos passos. Poucos minutos, muita clareza.

EC1 · estudo de caso

A pergunta que o ensaio salvou

No ensaio, perguntaram ao grupo fictício Fila Zero: "onde ficam guardados os dados dos clientes e quem acessa?". Ninguém sabia responder. Na apresentação final, eles tinham um slide sobre isso.

Para discutir em grupo

  1. Quais são as três perguntas mais difíceis que a banca pode fazer ao grupo de vocês?
  2. Que parte do relatório final responde a cada uma?
