C1–C3 · conceitos

Do processo ao CRUD

C1

Plano operacional

Como o negócio funciona no dia a dia: processos, estrutura, equipe e parceiros. Cada processo importante vira uma funcionalidade do sistema.

C2

CRUD: as quatro operações

Create (cadastrar), Read (listar), Update (alterar) e Delete (apagar). Quase todo sistema começa por elas.

No PHP, a conexão com o MySQL usa PDO, como vocês estão vendo na Web II.

1-- C: cadastrar2INSERT INTO cliente (nome, email)3  VALUES ('Ana', 'ana@email.com');45-- R: listar6SELECT id, nome FROM cliente7  ORDER BY nome;89-- U: alterar10UPDATE cliente SET nome = 'Ana Souza'11  WHERE id = 1;1213-- D: apagar14DELETE FROM cliente WHERE id = 1;
C3

Protótipo com IA, autoria de vocês

O GitHub Copilot ajuda a montar formulários e consultas, mas quem decide a estrutura e confere a segurança são vocês.

Nunca monte SQL juntando texto digitado pelo usuário: use consultas preparadas, para evitar SQL injection.

EC1 · estudo de caso

O protótipo que travava no caixa

Num teste do protótipo de uma loja fictícia, o cadastro de cliente funcionava, mas o caixa precisava de sete telas para registrar uma venda. Com fila, o vendedor voltou para o caderno.

Para discutir em grupo

  1. Que operação do negócio o sistema precisa deixar mais rápida?
  2. Que tabela e que tela fazem falta para a venda sair em um passo?

Caso fictício, criado para a aula.
