Do processo ao CRUD

C1

Plano operacional

Como o negócio funciona no dia a dia: processos, estrutura, equipe e parceiros. Cada processo importante vira uma funcionalidade do sistema.

C2

CRUD: as quatro operações

Create (cadastrar), Read (listar), Update (alterar) e Delete (apagar). Quase todo sistema começa por elas.

No PHP, a conexão com o MySQL usa PDO, como vocês estão vendo na Web II.

C3

Protótipo com IA, autoria de vocês

O GitHub Copilot ajuda a montar formulários e consultas, mas quem decide a estrutura e confere a segurança são vocês.

Nunca monte SQL juntando texto digitado pelo usuário: use consultas preparadas, para evitar SQL injection.

Passo 2 · item 2 da atividade

O banco no MySQL do XAMPP

Faça assim:
  1. Abra o painel do XAMPP e clique em Start no Apache e no MySQL. Os dois ficam verdes.
  2. No navegador, abra http://localhost/phpmyadmin.
  3. Clique na aba SQL, cole todo o banco.sql do grupo (o da aula 11) e clique em Executar.
  4. Na lista da esquerda, clique no banco e confira se as tabelas apareceram e se a produto tem os dados de teste.

O MySQL não fica verde? Outro programa está usando a porta 3306 (outro MySQL instalado no computador, por exemplo). Feche o outro programa ou peça ajuda à professora para trocar a porta.

Passo 3 · item 3 da atividade

A conexão do PHP com o MySQL

O PHP conversa com o MySQL pelo PDO, como vocês estão vendo na Web II. A conexão fica num arquivo só, o conexao.php, e todas as páginas usam esse arquivo com require. Mudou a senha ou o nome do banco? Muda num lugar só.

Faça assim:
  1. Dentro da pasta htdocs do XAMPP (no Windows, C:\xampp\htdocs), crie a pasta do projeto, por exemplo lanche-ja, e abra no VS Code.
  2. Crie o conexao.php e o teste.php com o código abaixo. Troque lanche_ja pelo nome do banco de vocês.
  3. Abra http://localhost/lanche-ja/teste.php. Tem que aparecer "Conectou!" com o número de produtos.
conexao.php
1<?php2// conexão com o MySQL do XAMPP: usuário root, sem senha, banco lanche_ja3$pdo = new PDO(4    'mysql:host=localhost;dbname=lanche_ja;charset=utf8mb4',5    'root',6    ''7);89// se um comando SQL der errado, o PHP mostra o erro em vez de ficar calado10$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
teste.php
1<?php2require __DIR__ . '/conexao.php';34// se chegou até aqui, a conexão funcionou5$total = $pdo->query('SELECT COUNT(*) FROM produto')->fetchColumn();6echo "Conectou! O banco tem $total produto(s).";

Apareceu Unknown database? O nome do banco no conexao.php não é igual ao do phpMyAdmin. Apareceu Connection refused? O MySQL não está ligado no XAMPP. Apareceu o código na tela, em vez da página? O endereço tem que começar com http://localhost/: arquivo PHP aberto com dois cliques não roda.

Passo 4 · item 4 da atividade

O cadastro: o C do CRUD

A mesma página mostra o formulário e, quando ele é enviado, grava no banco. Repare em três cuidados: o trim e o if conferem os dados antes de gravar; o prepare com marcadores (:nome, :preco) impede o SQL injection; e o htmlspecialchars mostra a mensagem como texto.

Faça assim:
  1. Crie o cadastrar.php com o código abaixo.
  2. Abra http://localhost/lanche-ja/cadastrar.php e cadastre um produto.
  3. Confira no phpMyAdmin: clique na tabela produto › Visualizar. O produto novo está lá?
cadastrar.php

Passo 5 · item 5 da atividade

A listagem: o R do CRUD

O SELECT busca os produtos, o fetchAll traz todos numa lista e o foreach monta uma linha da tabela para cada um. O number_format mostra o preço no jeito brasileiro: R$ 16,00.

Faça assim:
  1. Crie o produtos.php com o código abaixo.
  2. Abra http://localhost/lanche-ja/produtos.php: aparecem os produtos de teste e os que vocês cadastraram.
  3. Use os links para ir e voltar entre o cadastro e a lista.
